Questions d'Investigation d'Atelier

Synthèse de Cours : Atomes, Molécules, Ions & Alliages

1. L'Atome & Sa Neutralité Électrique :
Un atome est constitué d'un noyau central (protons de charge $+e$ et neutrons neutres) entouré d'un nuage électronique (électrons de charge $-e$).
Dans un atome neutre : $$\text{Nombre de protons} = \text{Nombre d'électrons} = Z \text{ (numéro atomique)}$$
2. La Molécule :
Groupement électriquement neutre d'atomes unis par liaisons covalentes.
Exemples de soudage/métallerie : $\text{Dioxygène } O_2 \text{ (chalumeau)}$, $\text{Eau } H_2O$, $\text{Dioxyde de carbone } CO_2 \text{ (soudure MAG)}$, $\text{Méthane } CH_4$.
3. Les Ions (Cations & Anions) :
• Cation (ion positif) : Atome métallique ayant perdu un ou plusieurs électrons.
Exemples : $\text{Fer ferreux } Fe^{2+}$, $\text{Fer ferrique } Fe^{3+}$, $\text{Aluminium } Al^{3+}$, $\text{Cuivre } Cu^{2+}$, $\text{Zinc } Zn^{2+}$.
• Anion (ion négatif) : Atome ou groupe ayant gagné un ou plusieurs électrons.
Exemples : $\text{Ion chlorure } Cl^- \text{ (embruns marins)}$, $\text{Ion sulfate } SO_4^{2-}$, $\text{Ion hydroxyde } OH^-$.
4. Métaux Purs vs Alliages Métalliers :
• Acier au carbone : Fer (Fe) + Carbone ($\%C < 2\%$). Augmente la dureté et l'élasticité.
• Fonte : Fer (Fe) + Carbone ($\%C > 2\%$). Dure mais cassante.
• Acier Inoxydable : Fer (Fe) + Chrome ($\%Cr \ge 10,5\%$) + Nickel ($\%Ni$). Le chrome forme un film microscopique passif de trioxyde de dichrome $Cr_2O_3$ qui bloque l'oxydation.
• Inox 316L (qualité marine) : Contient $2,5\%$ de Molybdène (Mo) supplémentaire pour résister aux ions chlorures $Cl^-$ du littoral réunionnais.

Exercice 2.1 : Oxydation du fer et rouille $Fe(OH)_3$

Sur le front de mer de Sainte-Marie, la rouille se forme sous forme d'hydroxyde de fer (III) de formule $Fe(OH)_3$.

Exercice 2.2 : Nuance de l'acier S235

Une poutrelle IPN S235 livrée à Sainte-Clotilde a la composition massique : Fer $Fe = 98,20\%$, Carbone $C = 0,17\%$, Manganèse $Mn = 1,40\%$, Silicium $Si = 0,23\%$.

Exercice 2.3 : Comparaison Inox 304L vs 316L

L'Inox 304L contient 18% Cr et 9% Ni. L'Inox 316L contient 17% Cr, 12% Ni et 2,5% de Molybdène (Mo).

Exercice 2.4 : Électroneutralité du chlorure de cuivre

Dans un bain de décapage, on dissout des ions cuivre $Cu^{2+}$ et des ions chlorures $Cl^-$. La formule statistique s'écrit $CuCl_n$.

Exercice 3.1 : Protection sacrificielle du zinc (Galvanisation)

Données électrochimiques : $E^\circ(Zn^{2+}/Zn) = -0,76\text{ V}$ et $E^\circ(Fe^{2+}/Fe) = -0,44\text{ V}$. Le métal au potentiel le plus réducteur s'oxyde en premier en cédant des électrons.

Exercice 3.2 : Corrosion galvanique contact Inox / Aluminium

Données : $E^\circ(Al^{3+}/Al) = -1,66\text{ V}$ face à l'inox passif ($+0,10\text{ V}$). En l'absence de bague isolante au Port, l'aluminium s'oxyde très violemment.
