À Retenir : L'Essentiel du Cours

1. Puissances de 10 (exposants positifs et négatifs)

• Exposant positif : $10^n = 1\underbrace{00\dots 0}_{n\text{ zéros}}$ ($10^3 = 1\,000$).

• Exposant négatif : $10^{-n} = \dfrac{1}{10^n} = \underbrace{0,00\dots 0}_{n\text{ zéros}}1$ ($10^{-2} = 0,01$).

• Conventions clés : $10^0 = 1$ et $10^1 = 10$.

2. Règles de calcul fondamentales

• Produit : $10^a \times 10^b = 10^{a+b}$

• Quotient : $\dfrac{10^a}{10^b} = 10^{a-b}$

• Puissance de puissance : $(10^a)^b = 10^{a\times b}$

3. Notation Scientifique

Tout nombre décimal positif s'écrit de façon unique :

$a \times 10^n \quad \text{avec } 1 \le a < 10 \text{ et } n \in \mathbb{Z}$

Exemple : $15\,400\text{ mm} = 1,54\times 10^4\text{ mm}$ ; $0,0045\text{ m} = 4,5\times 10^{-3}\text{ m}$.

4. Encadrement de Tolérances d'Atelier

Une pièce de cote nominale $C$ et de tolérance $\pm t$ est conforme si sa mesure $x$ vérifie :

$C - t \le x \le C + t$

Si $x < C - t$ ou $x > C + t$, la pièce est déclarée au rebut.
